  1. Install WireGuard from the App Store.

  1. Download and install WireGuard for Windows.
  2. Click Add Tunnel and choose your downloaded .conf file.

  1. Install WireGuard from the Mac App Store.
  2. Open WireGuard and choose Import Tunnel(s) from File.
  3. Select your downloaded .conf file.
  4. Enable the tunnel.
  1. Install WireGuard: 
    sudo apt install wireguard -y
  2. Copy your downloaded .conf file to /etc/wireguard/wg0.conf
  3. Start the tunnel: 
    sudo wg-quick up wg0
  4. Enable on boot: 
    sudo systemctl enable wg-quick@wg0
  1. Download wstunnel v10.6.2 for your platform from GitHub.
  2. Download the wstunnel config from your device below.
  3. Run the wstunnel client in the background: 
    wstunnel client \
  -L "udp://127.0.0.1:51820:127.0.0.1:1194?timeout_sec=0" \
  ws://74.208.44.254:443
    Note: the server uses ws:// (not wss://).
  4. Import the wstunnel .conf file into WireGuard.
  5. Enable the tunnel.
