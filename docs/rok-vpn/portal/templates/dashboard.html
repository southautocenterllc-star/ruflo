Descarga WireGuard, luego importa tu archivo de configuracion personal desde el panel de arriba.

Como conectarse paso a paso

iPhone y Android
  1. Instala WireGuard desde App Store o Google Play.
  2. En este panel, toca Ver configuracion en tu dispositivo.
  3. En WireGuard toca + y elige Crear desde codigo QR.
  4. Escanea el codigo QR que aparece en pantalla.
  5. Activa el tunel. Listo.
Windows y macOS
  1. Descarga e instala WireGuard desde el boton de arriba.
  2. En este panel, toca Ver configuracion y descarga el archivo .conf.
  3. En WireGuard elige Importar tunel desde archivo.
  4. Activa el tunel.
Linux 
sudo apt install wireguard -y
# Descarga tu archivo .conf y copialo:
sudo cp rok-vpn.conf /etc/wireguard/wg0.conf
sudo wg-quick up wg0
Si tu red bloquea UDP — modo wstunnel (TCP 443)

Descarga la config wstunnel en vez de la directa. Funciona en redes empresariales, aeropuertos y hoteles.

wstunnel client \
  -L "udp://127.0.0.1:51820:127.0.0.1:1194?timeout_sec=0" \
  wss://74.208.44.254:443

Luego importa la config wstunnel en WireGuard y activa el tunel.
