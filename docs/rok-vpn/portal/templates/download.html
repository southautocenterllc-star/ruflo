Instrucciones de instalación

  1. Instala WireGuard desde la App Store / Google Play.
  2. Toca el botón + y elige Crear desde código QR.
  3. Escanea el QR de arriba.
  4. Activa el túnel.

  1. Descarga e instala WireGuard desde wireguard.com/install.
  2. Descarga el archivo .conf (conexión directa).
  3. En WireGuard, elige Importar túnel desde archivo.
  4. Activa el túnel.

sudo apt install wireguard -y
# descarga rok-vpn-{{ peer.name }}.conf y cópialo a /etc/wireguard/wg0.conf
sudo wg-quick up wg0

  1. Descarga wstunnel desde GitHub (wstunnel v10.6.2, archivo binario para tu plataforma).
  2. Descarga el archivo .conf (wstunnel).
  3. Ejecuta el cliente wstunnel en segundo plano: 
    wstunnel client \
  -L "udp://127.0.0.1:51820:127.0.0.1:1194?timeout_sec=0" \
  ws://74.208.44.254:443
    El servidor escucha en ws:// (sin TLS). Con wss:// falla el handshake.
  4. Carga la config wstunnel en WireGuard.
  5. Activa el túnel.
