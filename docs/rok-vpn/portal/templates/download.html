Setup instructions

  1. Install WireGuard from the App Store / Google Play.
  2. Tap the + button and choose Create from QR code.
  3. Scan the QR code above.
  4. Turn the tunnel on.

  1. Download wstunnel desde GitHub (wstunnel v10.6.2, archivo binario para tu plataforma).
  2. Download the .conf (wstunnel).
  3. Ejecuta el cliente wstunnel en segundo plano: 
    wstunnel client \
  -L "udp://127.0.0.1:51820:127.0.0.1:1194?timeout_sec=0" \
  ws://74.208.44.254:443
    El servidor escucha en ws:// (no TLS). With wss:// falla el handshake.
  4. Load the wstunnel config into WireGuard.
  5. Turn the tunnel on.
